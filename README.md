# FEVASF - Implantação do DSpace 7.6.1

## Apresentação

Documentação técnica da implantação do Repositório Institucional
da FEVASF utilizando a plataforma DSpace 7.6.1.

## Infraestrutura utilizada

- Windows 10
- DSpace 7.6.1
- Angular
- Java
- Apache Tomcat 9
- PostgreSQL
- Apache Maven 3.9.6
- Apache Ant 1.10.14
- Nginx 1.25.3
- No-IP DUC
- HTTPS

## Características da implantação

A solução foi implantada em servidor Windows, com integração
entre o backend DSpace, frontend Angular, Tomcat e Nginx.

O acesso externo utiliza DNS dinâmico e certificado HTTPS,
considerando as limitações de conectividade sob CGNAT.

## Repositório institucional

https://fevasf-repositorio.ddns.net/home

## Objetivo

Documentar uma implantação de repositório institucional
utilizando ferramentas gratuitas e infraestrutura de baixo custo.
